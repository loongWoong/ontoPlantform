# 本体关系图视图（v3：力导向 + 分层卡片双视图）

本体页「关系图」子页签同时提供两种展示方式：默认的零依赖力导向图谱（`2D` / `2.5D` / `3D`，带图数据库风格聚类），以及可切换的分层卡片图。布局与投影都是确定性纯函数：同一个本体、同一个 seed 每次得到完全相同的坐标，不在渲染期使用 `Math.random()` 或 `Date.now()`。

## 入口与切换

- 位置：本体页 →「已发布结构」卡片内的 `表格 / 关系图 / 工程流` 子页签。
- `表格`：保留原有 AI 草稿、对象、关系、词表表格及编辑抽屉。
- `关系图`：隐藏表格类内容，只渲染图谱；`frozen`（已发布）时详情条不出现编辑按钮，草稿态可直接从详情条进入对象/关系编辑。
- 子页签内用「力导向 / 分层卡片」分段控件切换展示方式，`aria-pressed` 标识当前视图；力导向专属的 `2D / 2.5D / 3D`、聚类与重新布局控件只在力导向下出现，分层卡片下隐藏，避免出现无效操作。
- 默认视图仍是 `表格`，不影响原有工作流；切到关系图不会写入后端。

## 分层卡片视图

- 复用 `frontend/src/lib/ontologyGraph.ts` 的从左到右分层布局：对象是 216px 宽卡片，关系是正交折线 + 箭头，回边/自环保留虚线语义。
- 卡片展示对象名、业务说明换行、属性数与关系数；点击卡片/关系仍走同一套选中、关联高亮和详情条。
- 摄像机、滚轮缩放、拖拽平移、关系名称开关、「只看相关」和全屏展开与力导向共用；分层视图只做平移，不做 3D 旋转。
- 切换到分层视图时会按卡片边界自动适应画布，切回力导向时重新按力模型投影适应。

## 三种空间模式

| 模式 | 投影 | 操作 |
| --- | --- | --- |
| `2D` | 正交平面投影，`z` 恒为 0 | 拖动平移 |
| `2.5D` | 固定斜视角的透视投影，有前后景深 | 拖动平移 |
| `3D` | 透视投影 + 俯仰/偏航相机 | 左键拖动旋转，`Shift` + 左键拖动平移 |

模式切换会重置相机（`2D`/`2.5D` 回到正视角，`3D` 回到默认斜角）并重新适应画布。`2.5D` 的镜头固定，所以适合作为“有纵深但不必操作”的默认展示；需要检查空间关系时切到 `3D` 旋转。

## 图数据库式聚类

- 社区发现：纯函数、确定性的 Louvain 局部移动算法；用 FNV-1a 字符串哈希决定遍历顺序，社区编号按最小成员名规范化，因此结果可复现。
- 聚类参与力模型：每个社区有独立引力中心（`cluster gravity`），节点离自己的社区中心越远拉力越大；同时保留节点排斥、边弹簧、全局向心力和碰撞间距。
- 视觉：每个聚类绘制柔和凸包（半透明填充 + 虚线描边）、聚类标签与数量，底部工具条有可点击的聚类图例；节点按聚类着色（蓝/绿/琥珀/红/紫），未聚类节点用中性色。
- 图例 chip 的 `title` 列出该聚类的成员对象，悬浮即可确认分组；「聚类」开关可整体隐藏凸包与图例但保留节点着色。
- 单社区是合法结果：例如“收费站—车道—车辆—通行交易”这个星形本体只有一个社区；不强行拆成假聚类。多连通分量或更大的本体就会看到多个凸包。

## 视觉整理

- 节点由外到内是虚线选中环、聚类光晕、描边圆、内环和实心核；选中时环变实、相关节点保留聚类色，未相关节点降到 34% 不透明度。
- 关系线加一层与画布同色的宽描边作为“减淡底”，避免细线压在网格上发虚；关系标签改为更轻的圆角盒和 10px 字号，相关/选中时才切到蓝色语义色。
- 聚类用低透明度凸包、外围细描边、顶部小胶囊标签（`聚类 01 · n`）和底部图例共同表达；聚类关闭时标签/凸包/图例一起隐藏，节点回到中性色。
- 材质保持平台的暖单色平面规则：不使用渐变、玻璃拟态或重阴影，只保留极低透明度的投影和 1px 结构线。

## 交互

| 操作 | 行为 |
| --- | --- |
| 点击节点/关系 | 选中并在底部详情条展示属性、出入向关系、基数、描述；关联对象/关系高亮，其余降暗 |
| 点击空白 | 取消选中 |
| 滚轮 | 以指针为锚点缩放（0.12–2 倍） |
| 拖动画布 | 分层卡片、`2D`/`2.5D` 平移；`3D` 旋转 |
| `Shift` + 拖动 | `3D` 平移 |
| 工具条「力导向 / 分层卡片」 | 切换展示方式，重新适应画布；力导向专属控件随切换显示/隐藏 |
| 工具条 `2D / 2.5D / 3D` | 仅在力导向下出现，切换投影与空间布局，`aria-pressed` 标识当前模式 |
| 工具条「聚类」 | 仅在力导向下出现，显示/隐藏聚类凸包、标签与图例，状态 `aria-pressed` |
| 工具条「关系名称」 | 显示/隐藏关系标签；选中/相关关系仍保留标签 |
| 工具条「只看相关」 | 以选中对象为中心，只保留直接邻居与相连关系；再次点击回到完整图 |
| 工具条「重新布局」 | 仅在力导向下出现，seed + 1，重新跑力模拟；相同 seed 会得到相同结果 |
| 工具条「展开」 | 原生 `<dialog>` 全屏查看；Esc/关闭按钮退出，焦点回到展开按钮；全屏内仍可切换两种视图 |
| 缩放控件 | 缩小、放大、适应画布；适应画布按当前视图重新计算边界 |
| 键盘 | 节点/关系、视图切换、缩放与工具按钮均可 Tab 聚焦，Enter/Space 激活 |

## 实现位置

- `frontend/src/lib/forceGraph.ts`：纯布局/投影函数。
  - `layoutForceGraph(ontology, { mode, seed })` → `ForceGraphLayout`（节点、边、聚类、悬空关系）。
  - `defaultForceView(mode)` → 默认相机。
  - `projectForceGraph(layout, view)` → 屏幕坐标、路径、标签盒、聚类凸包。
- `frontend/src/components/OntologyGraph.tsx`：双视图画布、工具条、详情条、全屏、指针/滚轮/键盘交互；同一套摄像机与选中状态在两种布局间复用。
- `frontend/src/styles.css`：力导向节点/光晕/凸包/聚类胶囊/图例、分层卡片、视图切换与响应式样式。
- `frontend/src/lib/ontologyGraph.ts`：v1 的分层卡片布局，v3 重新接入关系图组件；其 31 项旧测试继续作为回归保护。

## 布局细节

- 力模型常量：`ITERATIONS=220`、`REPULSION=4600`、`SPRING=0.026`、`CLUSTER_GRAVITY=0.016`、`CENTER_GRAVITY=0.0012`、`DAMPING=0.72`、`MAX_SPEED=9`、`COLLISION_GAP=16`。
- 初始位置由本体名、节点名与 seed 的哈希决定；节点按名称排序，避免对象插入顺序影响布局。
- `2.5D`/`3D` 共享三维力模拟；`2D` 只模拟 `x/y` 并把 `z` 置零。
- 力模拟结束后按节点数把整体跨度归一到 `280 + 55 × n`（上限 1400），避免 4 节点图只占 750px 画布中间一小块，同时不放大节点半径。
- 普通边用二次贝塞尔曲线；self loop 用三次贝塞尔小环；关系标签按 8 个字宽换行，标签盒参与投影与边界计算。
- 投影按深度从远到近排序，近处节点绘制在后；3D 透视使用 `PERSPECTIVE=820`。
- 聚类凸包：每个节点取 8 个外扩点，单调链求凸包，再用平滑闭合路径连接；凸包只做视觉分组，不参与点击。

## 样式与无障碍

- 全部颜色/圆角/字体来自 `frontend/src/styles.css` 的 `:root` token；新增紫罗兰聚类 token `--violet-bg`/`--violet-ink` 与 `--cluster-*` 局部变量。
- 节点/关系均带 `role="button"`、`tabIndex`、`aria-pressed` 与包含可见文本的 `aria-label`；聚类凸包与选中环设为 `aria-hidden`/`pointer-events: none`，聚类图例用带 `title` 成员清单的 chip 呈现。
- 「力导向 / 分层卡片」用 `role="group"` + `aria-pressed` 的分段按钮表达，两种视图切换不改变选中对象；强制导向控件按当前视图渲染，避免读到无效按钮。
- 窄屏（≤760px）工具条自动换行、聚类图例换行；≤640px 画布高 420px，不产生横向溢出；分层卡片在窄屏保持 65% 可读下限，超出部分可拖拽/缩放/全屏查看。
- 全屏 `<dialog>` 复用同一套画布与工具条，全屏时画布按视口高度重新适应；视图切换与选中状态在全屏内外保持一致。

## 已知取舍

- 社区发现是确定性的 Louvain 局部移动实现，不追求与 Neo4j GDS 等图数据库的模块度结果逐位一致；目标是在浏览器里零依赖、可复现地展示聚类结构。
- 单社区星形本体只显示一个凸包；这是图结构真实结果，不是聚类失效。
- 极端稠密图在首屏适应后节点/标签会变小，可放大、全屏或用「只看相关」聚焦局部。
- 分层卡片是固定的从左到右布局，不做拖拽节点；窄屏下会自动缩到可读下限，超宽图层需要平移或全屏查看。
- 3D 旋转不自动重新适应画布（避免每帧重置相机）；旋转后可用「适应画布」恢复构图。
- 图视图的「力导向 / 分层」状态不写 URL；刷新页面回到默认「表格」页签，再进入关系图时默认力导向。
