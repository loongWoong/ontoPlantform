# 本体关系图视图（v1）

本体页新增「关系图」子页签，用于把已发布/草稿本体从表格结构转成可交互的分层关系图。视觉参考 `uom-forge` 的 `ModelGraph`（点阵画布、白底圆角卡片、正交圆角连线、关系名称胶囊、缩放/全屏/聚焦工具条），但只使用本仓库现有设计 token，不引入任何前端依赖。

## 入口与切换

- 位置：本体页 →「已发布结构」卡片内的 `表格 / 关系图` 子页签。
- `表格`：保留原有 AI 草稿、对象、关系、词表表格及编辑抽屉。
- `关系图`：隐藏表格类内容，只渲染图谱；`frozen`（已发布）时详情条不出现编辑按钮，草稿态可直接从详情条进入对象/关系编辑。
- 默认视图仍是 `表格`，不影响原有工作流；切到关系图不会写入后端。

## 交互

| 操作 | 行为 |
| --- | --- |
| 点击节点/关系 | 选中并在底部详情条展示属性、出入向关系、基数、描述；关联对象/关系高亮，其余降暗 |
| 点击空白 | 取消选中 |
| 滚轮 | 以指针为锚点缩放（0.12–2 倍） |
| 拖拽画布 | 平移 |
| 工具条「关系名称」 | 显示/隐藏关系标签，状态 `aria-pressed` |
| 工具条「只看相关」 | 以选中对象为中心，只保留直接邻居与相连关系；再次点击回到完整图 |
| 工具条「展开」 | 原生 `<dialog>` 全屏查看；Esc/关闭按钮退出，焦点回到展开按钮 |
| 缩放控件 | 缩小、放大、适应画布；窄屏首屏最低保持 0.65 倍可读比例 |
| 键盘 | 节点/关系、缩放与工具按钮均可 Tab 聚焦，Enter/Space 激活 |

## 布局与路由（`frontend/src/lib/ontologyGraph.ts`）

纯函数 `layoutOntologyGraph(ontology)` 返回确定性的 `{ width, height, nodes, edges, objectCount, relationCount, danglingRelations }`，不依赖浏览器。

- 分层：DFS 做环检测，回向边不参与最长路径分层；同层按前驱重心排序，减少交叉。
- 卡片：固定宽 `216`，高度随名称换行增长；名称按 11 个字宽单位换行。
- 路由：相邻层走层间空隙的正交折线（`Q` 圆角）；跨多层的长边统一走节点下方走廊，垂直段落在层间空隙，避免穿过中间层卡片；回向边同样走外侧走廊；self loop 用 `C` 小环。
- 标签：关系名称按 8 字宽单位换行；同一对 source/target 的多条关系共享路径时，按各自真实高度纵向排开；长边/回向边标签在走廊下方，走廊逐条下移，避免标签互压。
- 画布尺寸包含全部节点、连线与标签，空本体返回 88×88 的空画布。

## 样式与无障碍

- 全部颜色/圆角/字体来自 `frontend/src/styles.css` 的 `:root` token；画布背景为 22px 点阵 `radial-gradient(var(--line) …)`。
- 次要文字使用 `--muted`（白底对比度 ≥ 4.5:1），不使用 `--faint` 作为小号正文色。
- 节点/关系均带 `role="button"`、`tabIndex`、`aria-pressed` 与包含可见文本的 `aria-label`；axe（`label-content-name-mismatch`、`color-contrast`）当前无违规。
- 窄屏（≤640px）画布高 420px，工具条自动换行，不产生横向溢出。

## 已知取舍

- 布局是零依赖的简化分层实现，不是完整 ELK；极端稠密图上长边走廊会抬高画布高度，首屏 fit 后字号会变小，可放大或全屏查看。
- 图视图不写 URL 状态；刷新页面回到默认「表格」页签。
- 关系连线当前按关系逐条绘制；同一 source/target 的多条关系共享路径时箭头重合，通过标签错开展示语义差异。
