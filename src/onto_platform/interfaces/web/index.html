工作空间

工作空间是隔离容器：每个空间拥有独立的本体、数据、能力与运行时（design.txt §4）。

运行时索引 -

Kernel 是唯一事实来源；这里展示已发布到运行时的本体与能力。

尚无运行时先在本体页发布一个本体。

三链路一览

design.txt §34：数据链路 → 能力链路 → 智能链路，全部经 RuntimeGateway 防腐层进入 Kernel。

① 数据链路

数据源 → 投影 → Gateway → Kernel。
外部数据映射为业务对象，平台不存第二份状态。

② 能力链路

能力（python / workflow / agent）→ invoke → Kernel。
业务行动改变世界，留下变更与审计。

③ 智能链路

Ask（确定性）与 Agent（LLM 循环）→ 读世界、调能力。
用户看到业务语言，不是技术语言。

本体定义 -

对象 / 关系 / 业务术语。发布后定义锁定不可修改（v0.1：如需演进请新建工作空间）。

本体已发布，定义已锁定。运行时以发布版本为准；如需修改对象 / 关系 / 术语，请创建新的工作空间（v0.1 边界）。
尚无本体创建一个，或选择已有工作空间。
